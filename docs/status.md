| 项目 | 验证范围 |
| --- | --- |
| macOS 简体 CLI | 本机 macOS 27.2、Claude 4.29.0 第三方 Gateway，注入及中文可见通过 |
| macOS 真实 magpie 自动加载 | 本机正常退出 Claude 后从原入口重新启动，无手动 apply；Code 主界面中文可见、9229 端口关闭 |
| macOS 首次准备 | 需用户正常退出后运行 `runtime-setup`；尚未完成从零冷安装的全链路验收 |
| macOS 官方目录 | 基础/动态资源在本机兼容检查通过；冷缓存联网下载及其他机器仍待验证 |
| Windows 首次自动准备 | 历史本机商店版 2.42304.0 通过；仅合并 allowDevTools、备份及漂移拒绝夹具通过 |
| Windows 简体启动 | 历史默认及保存偏好后原入口启动通过，3.1623.1.0 另有自动加载实测 |
| 繁体、其他系统/Claude 版本、全部界面 | 尚未完成实机验收 |

单元/隔离宿主/打包测试不能代替真实应用验收，macOS 本机通过也不能代替当前提交的三平台 CI。发布前按[发布检查](release.md)核对当前提交和同一 tarball；历史细节保留在[验证记录](validation.md)。
