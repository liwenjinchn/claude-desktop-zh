Claude 中文

claude-desktop-zh

为第三方模式加载官方中文界面，继续使用原来的设置和会话。

语言

Windows 首次使用

  1. Claude 已打开时，通过「文件 → 退出」正常退出。
  2. 看到「中文已准备好」通知后，从原入口打开 Claude。

使用时保持 magpie 运行。加载时可能短暂出现调试窗口和文件选择框，完成后自动收起。

macOS

  1. 给 magpie 授予「辅助功能」权限，并保持 magpie 运行。
  2. 打开 Claude 的第三方模式窗口；插件会在后台自动加载中文。

需要 Claude 已开启开发者工具。首次或自动加载失败时，可在「语言资源维护」工作台点击「立即加载中文」。加载通过 Claude 自己的主进程调试器完成，不修改 Claude.app、签名或网关；调试器会在加载后关闭。页面刷新（⌘R）不会自动重新加载，需要手动点击。

如何加载

Windows 在每次 Claude 启动后运行本地脚本；macOS 在 magpie 运行时监听新的 Claude 进程，自动把官方中文语言文件加载到当前窗口内存。两条路径都不修改核心应用文件。
